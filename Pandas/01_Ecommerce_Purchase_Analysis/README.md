# 🛒 Ecommerce Purchase Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an Ecommerce Purchases dataset using **Python** and **Pandas**.

The analysis focuses on customer purchasing behavior, payment methods, language preferences, purchase timings, and email providers.

---

## 🛠 Technologies Used

- Python
- Pandas

---

## 📂 Dataset

- **Dataset:** Ecommerce Purchases.csv

---

## 📊 Analysis Performed

The following business questions were solved:

1. Display Top 10 Rows
2. Display Last 10 Rows
3. Check Data Types of Each Column
4. Check Missing Values
5. Find Number of Rows and Columns
6. Find Highest and Lowest Purchase Price
7. Calculate Average Purchase Price
8. Count Customers Using French (`fr`) Language
9. Find Job Titles Containing "Engineer"
10. Find Email by IP Address
11. Count Mastercard Users with Purchase Price Above 50
12. Find Email by Credit Card Number
13. Count Purchases Made in AM and PM
14. Count Credit Cards Expiring in 2020
15. Find Top 5 Most Popular Email Providers
