# 💼 Salary Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an employee salary dataset using **Python** and **Pandas**.

The objective is to analyze employee salaries, job titles, departments, and yearly salary trends while practicing data cleaning and aggregation techniques.

---

## 🛠 Technologies Used

- Python
- Pandas

---

## 📂 Dataset

- **Dataset:** Salaries.csv

---

## 📊 Analysis Performed

The following business questions were solved:

1. Display Top 10 Rows
2. Display Last 10 Rows
3. Check Dataset Shape
4. Dataset Information
5. Check Missing Values
6. Drop Unnecessary Columns
7. Overall Statistics
8. Top 5 Employee Names
9. Number of Unique Job Titles
10. Job Titles Containing "Captain"
11. Employees from Fire Department
12. Minimum, Maximum and Average BasePay
13. Replace Missing Values
14. Remove Rows with Missing Values
15. Find Job Title of ALBERT PARDINI
16. Total Pay of ALBERT PARDINI
17. Employee with Highest BasePay
18. Average BasePay by Year
19. Average BasePay by Job Title
20. Average BasePay of ACCOUNTANT
21. Top 5 Most Common Job Titles
22. Job Title with Highest Average BasePay
23. Year with Highest Average TotalPay
24. Top 10 Employees by TotalPay
25. Count Employees by Job Title
26. Most Common Job Title
