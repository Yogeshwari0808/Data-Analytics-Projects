# 👨‍💼 Employee Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an employee dataset using **Python** and **Pandas**.

The project focuses on employee salaries, departments, experience, missing value handling, and department-wise analysis.

---

## 🛠 Technologies Used

- Python
- Pandas

---

## 📂 Dataset

- Employee_Data_Analytics.csv

---

## 📊 Analysis Performed

The following operations were performed:

1. Display first 5 rows
2. Display last 5 rows
3. Check dataset shape
4. Display column names
5. Display dataset information
6. Statistical summary
7. Check missing values
8. Fill missing salary values with average salary
9. Find highest salary employee
10. Find lowest salary employee
11. Calculate average salary
12. Employees earning more than 50,000
13. Display Name and Salary columns
14. Sort employees by salary
15. Department-wise average salary
16. Count employees department-wise
17. Find employee with highest experience
18. Create Annual Salary column
19. Department-wise total salary
20. Department-wise maximum salary
21. Department-wise minimum salary
22. Employees with more than 3 years experience
23. Display IT department employees
24. Count unique departments
25. Rename Salary column
26. Export cleaned dataset
